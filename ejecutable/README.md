# KicksMind v1.0

Primera versión funcional de KicksMind, un sistema de reconocimiento y clasificación de sneakers desarrollado en Python.

## Características principales
- Interfaz gráfica para seleccionar imágenes.
- Clasificación de cinco categorías de sneakers:
  - Adidas Campus
  - Adidas Samba
  - Nike Air Force 1
  - Air Jordan 1
  - Air Jordan 4
- Algoritmo de clasificación Random Forest.
- Extracción de características mediante HOG, LBP y Box Counting.
- Procesamiento digital de imágenes.
- Modelo de clasificación previamente entrenado.
